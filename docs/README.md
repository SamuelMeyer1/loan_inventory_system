# Documentation

This folder contains project documentation and learning material.

- [todo.md](todo.md) tracks reported bugs and agreed improvements, with short names, stable IDs and completion status.
- `system-map.md` explains the system flow with Mermaid diagrams.
- `system-map.drawio` is a visual diagram that can be opened in diagrams.net.
- `dataskydd.md` explains local accounts, access control, privacy tools and required deployment decisions.

The running app does not need these files. They are here to make the project
easier to understand and maintain.
